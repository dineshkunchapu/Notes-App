# Notes Management Web Application (React)

A simple and responsive notes management web application built using **React.js**.  
The application allows users to create, view, and delete notes, with data persisted locally using the browser’s **Local Storage**.

This project was originally implemented using **vanilla JavaScript** and later **migrated to React** to understand component-based architecture, state management, and modern frontend development practices.

---

## 🚀 Features
- Create and delete notes
- Persistent storage using browser Local Storage
- Clean and minimal user interface
- Responsive design
- Component-based architecture using React

---

## 🛠 Tech Stack
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

---

## 🧠 Learning Outcomes
- Migrated a vanilla JavaScript application to React.js
- Implemented state management using `useState`
- Used `useEffect` for data persistence with Local Storage
- Built reusable components and passed data using props
- Improved UI maintainability and structure
